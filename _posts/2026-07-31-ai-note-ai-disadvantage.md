上半年挺魔怔的，在 AI 这个事情上，公司挺激进，本人也挺激进。4 月的时候，每人每月的 token 额度提高到了 1000 usd，而且 token 相比于官方正价是有折扣，所以额度远不止 1000 usd。  

半年下来，高强度的使用之后，渐渐回归一些理性。  

回想起来，前几个月我还在狂热地使用 slock（后面叫 raft, https://raft.build/ ）的 agent 协作平台。也在公司的内部分享文章里面写了关于 openai 的 symphony 这样的任务编排系统，agent 自动领任务，人类只是其中一环，看着很厉害，很高度自动化，仿佛大部分程序员已经被淘汰了的场景。  

但现实呢？产出是真的极大了，但质量不怎么好。虽然也让 agent 独立 review，让 agent 独立做 test，但始终还要人去把关。想来想去，ai 还是有蛮大缺陷的，在我看来，就是没有责任感，没有审美。至少现阶段是这样，过几个月可能又好一些。  

后面我不用 slock 了，因为它并不好用，实际上拖慢了我的开发进度。slock 自己加了一些提示词，以做到可以在一个 channel 里面让多个 agent 进行协作，但并没法把这个事情确定性的做好，时好时坏的，并且经过 slock 这一道之后，agent 的反应慢了一些，用起来挺难受的。  

不过，slock 这个思路还是挺好的，可以算做人与agent协作的一种不错的范式，等它更完善了再用。或者到时会有更好得多的范式了。  

为什么它没有被训练出责任感和审美呢？是做不到吗？为什么 ai 现在还没法完全替代我呢？是因为我脑子里有一些它不具备的知识吗？明明东西都已经摆到它面前了，我很确信，所有东西都给它了，为啥它的产出还是没有让我完全满意和放心呢？是我的境界问题，欣赏不了它，还是它确实就是还缺少些啥？   

agent 目前缺乏真正的架构师思维，它还不太会做减法，它经常追求局部最优，它经常不做妥协。这可能还是一些隐性知识在作怪，当前的团队规模，人员素质，项目周期，项目目标，等等，人会经常思考这些问题，从而做很多取舍，但这些没有明面的传达给 ai。
